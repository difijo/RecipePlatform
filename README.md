# Recipe Platform

A recipe platform developed as a project during my Software Engineering studies at UTB Zlín. The application allows users to explore and manage recipes.

## Features

- Browse and view recipes
- View recipe details and ingredients
- Add, edit, and delete recipes
- Search or filter recipes

## Technologies

- C#
- .NET

## Project Purpose

This project was created to practice application development with C# and .NET, focusing on clean structure and object-oriented programming principles.
